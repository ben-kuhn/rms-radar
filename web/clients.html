Configuring service codes in Winlink clients

Winlink clients only list gateways for the service codes you configure. If a Mercury, VardeFM, IONHF, MODEM73, DATA2G, or XARA gateway is missing from your client, add its code there.

Service codes group gateway channels. The Winlink API returns channels for the codes you ask for, and it has no wildcard. Only add codes you are entitled to use. Adding a code changes which gateways your client lists — you still need the matching mode or modem to connect.

What the codes mean

CodeMeaning
PUBLICMaritime and open amateur gateways, including emergency gateways that allow public access. This is the default in most clients.
MERCURYMercury HF community modems. Winlink advertises these channels as VARA; this map labels them Mercury.
VARDEFMVardeFM community modems. Winlink advertises these channels as VARA (VHF/UHF); this map labels them VardeFM.
MODEM73MODEM73 community packet modems. Winlink advertises these channels as Packet at 600 or 2400 Hz; this map labels them MODEM73 without a width.
DATA2GDATA2G community VARA modems. Winlink advertises these channels as VARA at 500 or 2400 Hz; this map labels them DATA2G without a width.
IONHFIONHF community modems. Winlink advertises these channels as ARDOP; this map labels them IONHF.
XARAXARA community modems. Winlink advertises these channels as VARA; this map labels them XARA. See XARA releases.
otherOther community projects or private group codes. Add the code in your client; the Winlink team does not publish private codes.

The official description is on Winlink — Gateway Channels.

Winlink Express Windows

  1. Open Settings → Winlink Express Setup.
  2. In the Service Codes field, enter the codes separated by spaces — for example PUBLIC, or PUBLIC MERCURY VARDEFM MODEM73 DATA2G IONHF XARA.
  3. Click Update.
  4. Update the channel list. Winlink Express notes that changing service codes requires updating the list of channels.

More information: Winlink quick setup guide (PDF) · Gateway Channels.

PAT Linux · macOS · Windows

  1. Run pat configure (or edit the configuration file it opens).
  2. Set the service_codes array, for example: 
    "service_codes": ["PUBLIC", "MERCURY", "VARDEFM", "MODEM73", "DATA2G", "IONHF", "XARA"]
  3. Save and restart PAT. pat rmslist uses these codes.

The default is ["PUBLIC"]. More information: getpat.io · PAT configuration source.

WoAD Android

  1. Open a session's RMS Channel Selection screen: edit a session → Destination address → RMS Channel Selection….
  2. In the lower menu, choose Service Codes.
  3. Enter one code per line, or separate them with spaces — for example PUBLIC MERCURY VARDEFM MODEM73 DATA2G IONHF XARA.
  4. Go back and choose Update via internet so the channel list reflects the new codes.

More information: WoAD documentation (see RMS Channel Selection → Service Codes).

RadioMail iPhone · iPad · Apple silicon Mac

  1. Open Settings → Stations → Directory.
  2. Under Service codes, list the additional codes you want, for example MERCURY, VARDEFM, MODEM73, DATA2G, IONHF, XARA.
  3. Non-public codes appear as a small label on directory rows and in the session picker.

More information: RadioMail manual (PDF, §11.6) · radiomail.app.

HTCommander Windows · macOS · Linux · Android · iOS · web

HTCommander's Winlink support is built around a bundled, offline directory of PUBLIC 1200-baud packet and VARA-FM gateways. Its documentation does not describe a service-code setting, so MERCURY and VARDEFM channels will not appear in its directory — use this map to find those gateways.

More information: HTCommander Winlink docs · offline gateway directory.

About this list

This map is unofficial and not affiliated with the Winlink Development Team or ARSFI. It fetches PUBLIC, MERCURY, VARDEFM, MODEM73, DATA2G, IONHF, and XARA from Winlink's public gateway API by default; the service-code dropdown shows the codes present in the returned data. The official gateway list and map are at winlink.org/RMSChannels.
