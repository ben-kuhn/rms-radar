Setting up a Winlink gateway

Make your gateway's modes and service codes visible to clients — and to this map. This page covers RMS Trimode and BPQ32/LinBPQ.

One frequency/mode pair per report. The Winlink channel database keys an advertised channel by its frequency and mode string. If you run several modes or service codes on one dial frequency, give each report a distinct mode label — VARA500, VARA, VARA2750, ARDOP2000, etc. Otherwise one report can replace another and some of the service codes will never show up.

Before you start

  • Your base callsign must be authorized by a Winlink administrator as a gateway.
  • Only publish a service you actually run 24/7, and only the modes you listen on.
  • PUBLIC is the open amateur code. Community projects also publish under their own codes — for example MERCURY, VARDEFM, MODEM73, DATA2G, IONHF, and XARA. Codes that are not public are private group codes.

RMS Trimode HF · Windows

  1. Open Settings → Registration and enter the gateway callsign and Winlink password.
  2. Open Settings → Site Setup; set the grid square and the default Service Code (normally PUBLIC).
  3. Open Settings → Channel Settings; add each frequency/mode pair with its operating hours and service code, then click Update.
  4. To publish more than one mode or service code on the same frequency, add one entry per mode and give each a distinct mode label (VARA500, VARA2750, ARDOP, …). Trimode still accepts one connection at a time.
  5. Restart Trimode and confirm the channels appear in the Winlink list and on this map.

More information: Winlink — RMS Trimode · RMHAM Trimode setup deck (PDF).

BPQ32 / LinBPQ HF · VHF/UHF · Windows · Linux

BPQ publishes channels with WL2KREPORT lines in each radio port (before ENDPORT). The first field is the service code: 

WL2KREPORT Service, Host, Port, Callsign, Locator, Hours, Freq, Mode, Power, Ant Height, Ant Gain, Ant Direction

Add one line per service code, frequency, and mode. This example publishes three service codes on the same 40 m frequency, each with a distinct mode label so the reports do not collide: 

WL2KREPORT PUBLIC,   api.winlink.org, 80, CALL-10, EM38xx, 00-23, 7102800, VARA500, 50
WL2KREPORT MERCURY,  api.winlink.org, 80, CALL-10, EM38xx, 00-23, 7102800, VARA,    50
WL2KREPORT VARDEFM,  api.winlink.org, 80, CALL-10, EM38xx, 00-23, 7102800, VARA2750,50

The same pattern works for project codes such as MODEM73 and DATA2G: give each report a distinct mode label (PKT2400, VARA2750, …) so the service codes do not collide.

HF frequency convention: Winlink stores the USB center frequency. If your radio tunes 7.041 MHz, the center is 7.0425 MHz. RMS Radar subtracts 1.5 kHz for display so the listed frequency matches the dial.

Verify the listing

After saving and restarting, check the official list at winlink.org/RMSChannels and the service-code dropdown here. The CMS can take a few minutes to update; this map refreshes hourly.

A note on labels

The label is reporting metadata — it does not change the modem's bandwidth or give the gateway another radio. Use the label clients should select (for example VARA500 for a 500 Hz VARA channel), and keep each frequency/mode label unique so every service code survives the database.
