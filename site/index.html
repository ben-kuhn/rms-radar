First launch on macOS or Windows: the app is not code-signed yet. On macOS, right-click the app and choose Open (or remove quarantine). On Windows, choose More info → Run anyway if SmartScreen shows a warning. Checksums are published with every release.

Everything in one map

Built for technical users and radio experimenters who want to test, compare, and promote free and open source Winlink modems.

⌘

Service-code aware

Fetch and filter PUBLIC, MERCURY, VARDEFM, MODEM73, DATA2G, IONHF, XARA, AETHER, and any private code you add.

≈

Propagation ranking

Built-in real-time estimates work offline; an optional VOACAP engine gives point-to-point HF forecasts.

◎

Live gateway map

Map, list, and mobile views with freshness, bands, modes, frequencies, and gateway details.

⇣

Works offline

Previously viewed map tiles and the gateway list are cached, so the map and ranking still work when the network is unavailable.

⌁

Docker first-class

One command, one data volume, multi-arch image, healthcheck, non-root, read-only root filesystem.

⌂

Runs locally

Native desktop windows for Windows, macOS, and Linux; the web build is a single CGO-free binary.

Self-hosting

From pull to map in one command.

The container includes the web server and the VOACAP engine. Run it on a NAS, Raspberry Pi, VPS, or home server behind Caddy, Nginx, or Cloudflare Tunnel.
